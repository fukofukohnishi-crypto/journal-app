# journal-app

言葉にする前の自分を、手で置いていく場所。個人用ジャーナリングアプリ。
詳細は [SPEC.md](./SPEC.md) を参照。

## 技術構成

- React + Vite
- 蓄積ビジュアルは SVG で描画（グラフライブラリ不使用）
- データは IndexedDB にローカル保存。サーバー・ログインなし

## Step 1（実装済み）

- 記録画面：強度スワイプ／種類の選択／体の選択（任意）／単語（任意）
- 記録が線として蓄積し、月ごとに一枚の絵になるビジュアル

## 開発

```bash
npm install
npm run dev
```
